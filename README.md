# Aspar Mapper

کنترل بازی‌های اندروید با موس و کیبورد (بدون روت، بدون Shizuku) – ساخته‌شده برای Galaxy S23 Ultra و بازی Oxide: Survival Island.

## چطور کار می‌کند

- یک سرویس کوچک با دسترسی سطح ADB (از طریق «اشکال‌زدایی بی‌سیم» خود گوشی) اجرا می‌شود.
- این سرویس موس و کیبورد بلوتوثی/USB را مستقیم از `/dev/input` می‌خواند و در «حالت بازی» آن‌ها را قفل (grab) می‌کند.
- کلیدها به لمس‌های مجازی (چند انگشتی) روی صفحه تبدیل می‌شوند: دکمه‌ها، جوی‌استیک WASD و چرخش دوربین با موس.

## ساخت APK با GitHub (بدون Android Studio)

1. در GitHub یک ریپازیتوری جدید بساز (Private هم اشکالی ندارد).
2. همه فایل‌های این پوشه را آپلود کن، **از جمله پوشه مخفی `.github`**.
   - اگر آپلود با کشیدن و رها کردن، پوشه `.github` را نبرد: در ریپو روی **Add file → Create new file** بزن، در اسم فایل بنویس `.github/workflows/build.yml` و محتوای همان فایل را کپی کن.
3. به تب **Actions** برو. ساخت خودکار شروع می‌شود (حدود ۵ دقیقه). اگر شروع نشد، روی **Build APK → Run workflow** بزن.
4. بعد از تیک سبز، در صفحه اصلی ریپو بخش **Releases → latest** فایل `AsparMapper.apk` را با گوشی دانلود و نصب کن.

هر بار که فایلی را تغییر بدهی، GitHub دوباره می‌سازد و نسخه جدید را می‌توانی روی نسخه قبلی نصب کنی.

## راه‌اندازی روی گوشی

همه مراحل داخل خود برنامه به فارسی توضیح داده شده. خلاصه:

1. اجازه «نمایش روی برنامه‌های دیگر» را بده.
2. **جفت‌سازی (فقط بار اول):** گوشی به Wi-Fi وصل باشد ← «شروع جفت‌سازی» ← در تنظیمات، اشکال‌زدایی بی‌سیم ← جفت کردن دستگاه با کد ← کد ۶ رقمی را در اعلان برنامه وارد کن.
3. **فعال‌سازی (بعد از هر ری‌استارت):** اشکال‌زدایی بی‌سیم را روشن کن ← «فعال‌سازی».
4. بازی را باز کن، از دکمه شناور «ویرایش کلیدها» را بزن و دایره‌ها را روی دکمه‌های بازی بکش ← ذخیره.
5. کلید <kbd>`</kbd> (زیر Esc) بین «حالت بازی» و «حالت موس معمولی» جابه‌جا می‌کند.

## نکته‌ها

- بعد از نصب نسخه جدید برنامه، یک بار دیگر «فعال‌سازی» را بزن.
- اگر بازی بعد از فعال‌سازی ورودی را نگرفت یا گزارش خطا دیدی، متن وضعیت بالای صفحه برنامه را بفرست.
- گزارش سرویس در `/data/local/tmp/aspar_mapper.log` ذخیره می‌شود.
