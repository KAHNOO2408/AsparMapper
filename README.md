# Shiraz City — Android

فایل نصبی بازی شهر شیراز (نسخه آزمایشی 0.5، arm64، مخصوص گوشی‌های قوی مثل S23 Ultra).

دانلود: ShirazCity.apk

تازه‌های این نسخه:
- آدم‌های جدید و واقعی‌تر (مرد و زن) با لباس‌های واقعی و جدا از بدن
- فروشگاه لباس: ۲۰ تیشرت، ۲۰ شلوار، ۲۰ کفش، ۲۰ کلاه برای مرد و جداگانه برای زن
- پول، منوی اصلی، منوی توقف، ذخیره بازی
- اسلحه فروشی (کلت، هفت‌تیر، یوزی) و شلیک
- گرافیک بالاتر (رندر Vulkan، سایه و Glow)
